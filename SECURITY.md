# Security policy

## Report a vulnerability

Report it privately through this repository's [vulnerability report form](https://github.com/Veridelta/vscode-veridelta/security/advisories/new). Please do not open a public issue for it.

## Scope

This policy covers the extension in this repository:

- How it runs the `veridelta` command.
- The notifications it shows.
- The report webview.
- The server definition it gives agent mode.
- Its workflows in `.github/workflows/`.

A problem in Veridelta itself goes to the [security policy of the Veridelta repository](https://github.com/Veridelta/veridelta/security/policy).
